## N1- 2026-08-30 - Setting up OpenSim
*Issue*: OpenSim 4.6 opening and then immediately closing without any error reports

*Steps*
- Running the app through terminal showcasing the issue that **no Java Runtime was installed**, so GUI couldn't start
- Installed JDK 17 through brew, app opened, but threw errors
	- `InaccessibleObjectException`- Java's stricter module system conflicts with older platform which was meant for Java8/11
	- And other depcration warnings/harmless warnings
- Tested on JDK11, by editing the conf fiel through sudo pointing it at the jdk 11 path allowing for app to launch without terminal

### Scripts Run

**Installing and testing JDK 11**
```bash
brew install openjdk@11
brew --prefix openjdk@11
echo "$(brew --prefix openjdk@11)/libexec/openjdk.jdk/Contents/Home"
"/opt/homebrew/opt/openjdk@11/libexec/openjdk.jdk/Contents/Home/bin/java" -version
```
 
**Editing OpenSim's config to default to JDK 11**
```bash
sudo nano "/Applications/OpenSim 4.6/OpenSim 4.6.app/Contents/Resources/opensim/etc/opensim.conf"
```
 
**Edit made inside the conf file:**
```
# before:
#jdkhome="jre"
 
# after:
jdkhome="/opt/homebrew/opt/openjdk@11/libexec/openjdk.jdk/Contents/Home"
```

**Result**: FIXED!
